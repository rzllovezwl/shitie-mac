# 阶段 1：无鼠标搜索与粘贴

测试版从构建号 16 开始提供阶段 1 功能。已提审的构建号 4 不变。

## 键盘操作

1. 在原应用的输入位置按 `⌘⇧V`。面板打开时搜索框自动获得焦点，可直接输入关键词。
2. 按 `↑` / `↓` 选择记录。搜索框为空时也可按 `←` / `→`；搜索框有文字时左右键留给光标移动。选中项会自动滚动到可见位置。
3. 按 `Return` 保留记录原格式粘贴；按 `⌥Return` 只以纯文本粘贴；按 `⌘Return` 只复制到系统剪贴板，不自动粘贴。图片和文件没有纯文本表示时，`⌥Return` 会提示且不改写剪贴板。
4. 按空格展开或收起详情；按 `⌘F` 从列表返回搜索框；按 `Esc` 先收起详情或清空搜索，再收起面板。鼠标单击、双击与右键操作继续可用。

历史记录改为紧凑列表，显示内容摘要、类型、来源应用、复制时间和可用缩略图。摘要仅用于展示；保存的原文及其格式不因列表压缩而变化。

## 自动粘贴的边界

唤起面板前会记录原应用及其输入焦点。面板收起后，应用尝试返回原应用；只有系统允许发送键盘事件、原应用在前台，且能够核对原输入焦点时，才发送 `⌘V`。若无法核对或权限不足，内容已复制到系统剪贴板，界面和菜单栏会提示用户手动按 `⌘V`。剪贴板内容本身仍可手动粘贴。

macOS 没有跨应用通用的“粘贴已被目标接收”回执，因此发出 `⌘V` 只能报告已发送，不能声称目标一定粘贴成功。部分应用不公开输入焦点给辅助功能接口，此时会退回手动粘贴。此过程不读取或保存输入框里的内容。

## 验证范围

键位映射测试覆盖搜索时的左右光标、列表选择、保留格式粘贴、纯文本粘贴、只复制和输入法组合键边界；独立剪贴板测试覆盖富文本与纯文本两种回写。Xcode 构建运行版本记录校验。桌面上的实际焦点恢复、不同目标应用对粘贴事件的响应和列表视觉效果，按用户偏好由用户自行测试。
