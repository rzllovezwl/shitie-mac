# 全局快速搜索

功能始于开发构建 320，本文按当前开发版 1.0.0（349）整理。商店候选中的粘贴行为见对应发布资料。

## 使用

默认按 `⌘⇧空格` 打开或收起独立搜索窗，也可从菜单栏选择“快速搜索”。设置 → 快捷键与权限 → 全局快捷键中可录制新组合键、恢复默认；冲突时保留原设置。设置 → 剪贴板中提供功能说明和打开入口。

搜索窗出现在鼠标所在屏幕靠上的中央，不修改底部剪贴板面板的关键词、类型、日期、收藏分类和滚动位置。未输入时展示最近复制的 10 条；输入后搜索全部保留的历史，支持文字、链接、文件名、来源应用、图片 OCR 文字和分组成员。多个词用空格分开时须全部匹配，优先展示标题相关结果，同级按最近复制时间排序。

已有图片识别缓存直接参与匹配。未识别的图片在后台依次识别，搜索框和空结果区域显示加载动画，结果陆续补充；关闭搜索后停止排队新图片，正在处理的一张可完成并缓存。识别速度取决于图片数量和系统模型首次加载时间，不保证首次搜索所有图片立即齐全。无需上传剪贴板内容。

| 操作 | 行为 |
| --- | --- |
| 输入文字 | 搜索全部历史；空格可正常输入，中文候选选字不被导航键截获 |
| ↑ / ↓ | 选择上一条或下一条结果 |
| 回车 / 双击结果 | 按设置中的复制格式复制，并尝试粘贴到唤起前的应用和输入位置 |
| ⌘↩ | 打开当前结果的预览 |
| Tab | 在搜索框和结果列表之间切换焦点 |
| 空格（结果列表获焦时） | 打开或关闭预览 |
| ⌘C / ⌘⇧C（结果列表获焦时） | 复制结果 / 复制纯文本；搜索框内仍是系统的文字复制 |
| ⌘F | 返回搜索框 |
| Esc | 先关闭预览或其弹层，再关闭搜索并回到原应用；原面板可见时恢复原面板 |
| 再按全局搜索键 | 收起搜索 |

预览复用现有文字、图片、文件及分组详情。图片可缩放、识别和翻译；编辑、标注、保存、文件授权等独立操作会先退出搜索，再进入对应流程。记录已删除或过期时不使用搜索快照写回剪贴板。

自动粘贴沿用原有权限和输入位置核对流程；未授权、目标应用已退出或输入位置无法确认时，复制成功后提示手动 `⌘V`。桌面贴图在搜索和粘贴交接期间让出键盘焦点。截图、标注、文字编辑、文件选择及卡片拖动进行中不会被快速搜索打断。

## 验证边界

- 代码回归：文字与 OCR 匹配、相关性、文件与来源、多关键词、分组成员、最近十条、摘要、选择稳定性、取消任务、输入法与键盘路由、自定义快捷键冲突、贴图焦点交接。
- 构建与打包：版本记录、开发签名、macOS 14 部署目标、旧系统翻译框架弱链接，以及现有回归脚本。
- 桌面确认由用户完成：全局唤起、窗口外观、实际中文输入法、鼠标双击、预览弹层的 Esc、微信与其他应用粘贴、多屏和全屏。未把代码通过视为这些交互已验收，未进行 App Store 提审。
