# 截图与图片标注

本文对应开发版 1.0.0（349）。截图与历史图片使用同一套标注工具，入口为截图完成后的浮动工具条，或选中图片后按 ⌘E、右键选择“标注图片…”。文字卡片的 ⌘E 会打开文字编辑器。

## 截图入口

⌥A 进入窗口／区域选择，点按窗口或拖选区域，⌥W 截取鼠标所在的整个屏幕，⌘⇧D 进入长截图。⇧⌘A 和 ⇧⌥A 分别在选区后直接识别文字或翻译，所有全局按键可在设置中修改。

开启冻结取景时，区域来自初始屏幕快照，点选窗口来自同轮窗口快照，不重新抓取之后的视频帧。窗口可选保留阴影，区域截图与导出按单层像素处理。标注图片、编辑文字和选择文件时仍可启动截图，当前编辑内容保留，新截图拥有独立编辑状态。

## 工具与交互

| 工具 | 使用方式 |
| --- | --- |
| 矩形 R、椭圆 O | 空心、实心及圆角样式，带与箭头一致的柔和阴影。Shift 锁单轴，Option 沿拖动方向约束等宽高，调整时固定对侧锚点 |
| 箭头 E | 下拉选择既有箭头样式，拖动绘制并调整方向、长度和粗细 |
| 箭头＋矩形 | 从箭头菜单选择组合样式，拖动结束自动生成圆角框与圆尾箭头。拖箭尾调整方向、长度，拖框角调整矩形，箭尖随之对准靠近箭尾的圆角并保留间距 |
| 文字 T | 点击输入，支持正常、描边与背景色样式，样式菜单预览浅底和深底效果 |
| 画笔 L、荧光笔 | 自由绘制，Shift 从落笔点画直线，荧光笔可调不透明度 |
| 划除 X | 在需要弃用的区域画圆角框和连接四角的叉号。默认 2 点，边框与叉号同宽，合并后使用 80% 不透明度，交叉处颜色均匀 |
| 遮盖 M | 马赛克或背景模糊，可选强度，保存时作用于对应范围 |
| 数字标记 | 连续点击自动编号，撤销后回退，可设置数字标记外圈线宽 |
| 放大镜 | 椭圆或小圆角矩形镜片，拖锚点调整范围、蓝色菱形调整倍率，玻璃镜框和折射在编辑与导出中一致 |
| 钢笔 P | 单击加节点，拖动拉出贝塞尔手柄，回车或双击完成，点击首节点闭合，Esc 取消未完成路径。已有节点与手柄可再调整 |
| 贴图 | 从剪贴板图片历史或本地文件选择，拖放定位，默认保持比例，Option 可自由调整宽高 |
| 区域高亮 | 保留框内亮度，压暗框外内容 |
| 裁剪 | 调整图片边界并确认，预览与最终保存使用同一裁剪范围 |

放大镜独立放在数字标记前。贴图、钢笔和区域高亮位于高级工具菜单，贴图来源使用右侧子菜单。主工具图标和下拉控件保持成组，空间不足时工具条等比例收紧，图标可悬停查看名称与快捷键。浅色背景也使用独立底衬、边缘与阴影保持可见。

## 编辑、复用与保存

选中已有标注元素可移动或缩放。⌘C／⌘V 复制粘贴元素，按住 Option 拖动选中元素可复制。文字编辑过程中使用系统文字复制粘贴，不会误切换工具。保存的可编辑记录保留底图和标注，重新打开可继续修改。

贴图支持 PNG、SVG、JPEG、TIFF、HEIC、GIF 和 BMP。单个输入上限 64 MB，导入时最长边限制 4096 像素，GIF 使用静态帧。内容嵌入标注记录，之后移动源文件不影响已有贴图。

“设置 → 截图与贴图 → 标注工具默认样式”可分别设置矩形、椭圆、箭头、文字、荧光笔、画笔、钢笔、数字标记与划除的默认颜色和线宽，下次打开编辑器生效。文字线宽指描边，数字标记线宽指外圈，部分工具的 0 值表示沿用自动尺寸。旧标注保留已保存的样式。

工具栏提供 OCR、翻译、复制、保存图片和钉到桌面等入口，具体可用项按截图／历史图片上下文变化。OCR、翻译过程显示可取消的扫描状态，扫描效果不会进入保存图片。图片覆盖翻译需要 macOS 15，文字预览的系统翻译弹窗需要 macOS 14.4。

## 验证范围

代码回归包含冻结帧来源、裁剪坐标、单层输出、箭头几何、组合箭头的圆角与间距、阴影、划除透明度、文字描边、放大镜、贴图、钢笔、元素复制及撤销、快捷键路由和窄屏工具条。实际视频窗口、屏幕缩放、触控板手势、颜色与视觉效果仍需用户在桌面确认。
