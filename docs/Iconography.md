# 界面图标

应用内界面图标取自 `lucide-static@1.59.0`。源文件通过 `Tools/GenerateLucideAssets.swift` 转为路径 PDF，放在 `ClipboardShelf/Assets.xcassets` 中；运行时无需加载图标字体。图标按模板图像渲染，随浅色和深色模式变色。Dock 和访达的应用图标独立维护：开发版 325 起采用用户选定的 B 方案叠卡图标，母版、生成说明与导出方法见 `docs/Branding/B-325/README.md`；原 RZL 素材和已导出的商店安装包保留。

开发版 347 起，菜单栏两张卡片在复制时交错并归位，单次 0.35 秒。界面搜索与日历使用统一线宽的自定义矢量图标，设置齿轮沿用线性样式并用左侧竖线分组，历史与收藏标签采用药丸形。独立“划除”工具使用圆角框加叉号图标，大小、颜色与线宽与相邻工具一致。

开发版 327 将菜单栏中遗漏的旧剪贴板轮廓更新为 B 方案的单色叠卡标识，保留左上／右下取景角。`ClipboardShelfApp.swift` 中的 `MenuBarArtwork.appIcon` 直接绘制 18 点矢量模板，系统负责明暗背景下的着色；录屏状态图标与计时保持原交互。功能菜单中表示“剪贴板”的通用图标继续使用 Lucide。

截图工具栏使用同一版本的原始 `icon-nodes.json` 生成 `LucideToolbar-*` 资源。生成时仅调整图形中心线的范围，线宽固定为 24 点画布上的 2 点；所有按钮再统一显示为 18 点（紧凑模式 16 点），避免单独缩放图标导致箭头、文字等线条粗细不一致。语言下拉箭头保持较小的图形范围，绘制箭头保留已确认的视觉尺寸。生成命令需要 Python 和 ReportLab：

实心矩形使用同库的 `square` 路径填充生成 `square-filled` 变体；数字标记与荧光笔分别采用 `list-ordered` 和 `highlighter`。收藏星标使用同库的 `star`。

```sh
python3 Tools/GenerateScreenshotToolbarAssets.py /path/to/lucide-static/package ClipboardShelf/Assets.xcassets
```

上游：[Lucide Icons](https://lucide.dev/icons)。许可文本随应用打包在 `ClipboardShelf/Resources/Lucide-LICENSE.txt`。

添加图标时，在生成脚本的 `iconNames` 和 `ClipboardShelf/Views/LucideIcon.swift` 中同时登记。下载固定版本的 `lucide-static` 包后运行：

```sh
swift Tools/GenerateLucideAssets.swift /path/to/lucide-static/package ClipboardShelf/Assets.xcassets
xcodegen generate
```

250 版钢笔和贴图采用同一 Lucide 1.59.0 图标库的 `pen-tool`、`image` 原始路径，使用 24 点画布和 2 点统一线宽的矢量 PDF，保持与现有工具相同的按钮状态和悬停说明。

251 版主要标注工具使用用户提供的“截图工具栏_线性图标_SVG套装”：原 SVG 保存在 `Tools/Assets/AnnotationIcons/`，通过 `Tools/ImportAnnotationIcons.swift` 生成 `AnnotationToolbar-*` 矢量 PDF。14 个原图标全部保留；套装之外的钢笔、贴图、下拉、撤销、关闭、钉住和完成沿用 Lucide 路径，并与该套装统一到 1.8 点线宽。调色盘使用提供的轮廓路径，主体填充跟随当前颜色，去掉描边。

252 版调色盘保留当前选色填充，以偶奇规则镂空三个圆孔，并恢复随系统明暗外观变化的外描边。区域高亮恢复原来的双层矩形图标。工具栏按固定尺寸和成组控件测量宽度，保持单行，空间不足时整排等比例收紧。

253 版将放大镜圆圈加大、手柄缩短，滚动截图采用图片轮廓与上下双箭头，线宽保持 1.8 点。马赛克采用圆角像素格，交错色块用不同透明度实现明暗层次，并随模板图标适配系统明暗外观。三个细调 SVG 位于 `Tools/Assets/AnnotationIcons/overrides/`，导入脚本优先使用它们，原套装保留。区域高亮保留双层轮廓，外框调整为圆角正方形。

254 版用 Lucide 的 `ellipsis` 三点图标作为“高级工具”入口，收纳添加图片、放大镜、钢笔和区域高亮。选中高级工具后，入口显示该工具的既有图标；选中普通工具时恢复三点图标。标准按钮宽 32 点，组间距 2 点，形状与选项仍有共同的悬停和选中背景。底板在 macOS 26 使用 `NSGlassEffectView` 的透明样式，旧系统回退为 `NSVisualEffectView` 磨砂材质，与截图放大面板一致。

255 版工具栏改用常规玻璃，并在内容视图内添加 78% 不透明度的系统窗口背景色底衬，保留 3 点玻璃边缘，减少密集底层文字与图标混在一起。底衬随系统外观更新，不拦截按钮点击。高级工具改为 2×2 图标网格，44 点点击区域、22 点图标，名称与快捷键仅作悬停说明与辅助功能标签。

256 版工具栏试调为原生透明玻璃，底衬不透明度从 78% 调为 70%（透明度从 22% 增加到 30%），继续随系统明暗外观变化并保留 3 点玻璃边缘。高级工具延续纯图标面板。

257 版工具栏底衬透明度调为 25%（不透明度 75%）。

258 版将所有标注工具栏线性图标的既有线宽统一乘以 1.2，图形路径、画布和显示尺寸不变。导入脚本按比例处理 SVG 的描边参数，保留原始文件；24 点画布的主线宽从 1.8 点增至 2.16 点。调色盘外描边和区域高亮内外框同步增加 20%。主栏多数图标显示线宽约 1.62 点，紧凑模式约 1.44 点，高级工具面板约 1.98 点。

259 版文字样式菜单沿用箭头和形状菜单的纯示意图行，直接展示当前颜色在浅、深底色下的正常、描边、背景色效果；名称用于悬停说明和辅助功能标签。放大镜标注采用可导出的玻璃镜框绘制：半透明渐变、内外边缘、反光弧、轻微折射与柔和投影，编辑与输出共用相同绘制，透明中心保持透明。

260 版放大镜形状菜单使用椭圆与小圆角矩形的纯示意图，整行可点击，名称仅用于悬停及辅助功能标签。矩形玻璃镜框的高光、轮廓和折射沿同一圆角路径绘制，编辑与导出保持一致。

261 版放大镜作为独立的图标与形状下拉组合放在序号前，使用与其他形状工具一致的共同悬停和选中背景。高级工具改为贴图、钢笔、区域高亮三个图标的竖直单列，44 点点击区域、22 点图标及悬停说明保持不变。

262 版下拉采用统一的原生 NSMenuItem 图示和文字行：80×38 点预览栏与 14 点文字，共用系统悬停、选中及键盘导航。形状图以模板模式适配深浅色和悬停状态，文字、遮盖与荧光笔保留实际效果色。颜色使用大圆角矩形及选色外圈，工具栏色块与下拉箭头共用悬停背景。

263 版针对 macOS 27 默认隐藏菜单图片的行为，在支持的系统上设置 `NSMenuItem.preferredImageVisibility = .visible`；macOS 14–26 沿用原生菜单，未引入额外系统要求。颜色按钮、色卡和选中外圈统一使用 `RoundedRectangle(style: .continuous)` 的系统连续圆角路径。

264 版下拉选项使用统一的 36 点行高、13 点文字和居中预览栏；整行点击保留菜单动作，选中项改用浅色强调背景，不再显示对号。高级工具图标限制在 20×20 点以内、不放大原图；色块仍为连续圆角，去掉额外选色外圈。原文、译文语言的父菜单继续由系统处理子菜单展开和键盘导航。

265 版高级工具固定使用既有 Lucide 三点资源旋转为竖排，选中工具只改变背景，入口图形保持稳定。下拉菜单按预览尺寸测量图文栏，间距统一为 8 点，最小宽度从 184 点缩至 132 点，标准预览上限从 56×24 调为 44×22 点；高级工具维持 20 点图标，颜色 26 点。选中动作在菜单退出后派发，避免打开贴图来源等下一层界面时重入菜单跟踪。

266 版高级工具“设置”采用 `lucide-static@1.59.0` 的 `settings` 路径，存入 `extra/settings.svg` 并通过相同导入流程生成模板 PDF；24 点画布下的有效线宽为 2.16 点，菜单显示尺寸与其余高级工具相同。贴图来源和翻译语言共用原生父菜单构造，保留系统的右侧展开箭头、悬停与键盘导航；来源选择仍在整个菜单退出后执行。

267 版贴图子菜单父项按实际 20×20 点绘制图标，原生图片框宽度为 20 点、高度为 30 点：去掉 28×18 图片框带来的额外水平留白与图标缩小，最终菜单行高与 36 点命令行保持一致。形状不加粗重绘，直接恢复同一矢量资源的相同显示比例与线宽。其他原生子菜单沿用同样的垂直留白规则。

268 版依据实际菜单截图补偿原生子菜单的图标起点：高级工具命令行只将预览图右移 2 点，文字起点保持 40 点不动；统一图标尺寸后两列分别对齐，颜色和其他样式菜单不受影响。
