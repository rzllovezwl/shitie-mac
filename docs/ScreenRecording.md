# ClipHoook 录屏

本文对应开发版 1.0.0（349）。

从菜单栏“录屏…”或 ⌥R 进入选区。拖选区域、点击窗口，或从控制条切换整个屏幕（鼠标所在显示器）。区域选好后可移动和拖八个锚点调整；Shift 单轴、Option 等宽高约束沿拖动方向。录屏不冻结桌面。

录制前确认系统声音、麦克风和选项，点绿色实心播放三角或再按 ⌥R 开始，结束按钮使用红色实心方块。默认不倒计时、省空间（最高 1080p）、30 fps、系统声音开启、麦克风关闭、显示指针、突出鼠标点击。旧版存下来的旧默认项会更新一次，之后记住用户自行调整的值；其他设置保留。选项支持 0/3/5 秒、原始清晰度、60 fps、麦克风设备、鼠标点击提示、隐藏控制条。首次启用麦克风并开始录制时申请权限。

鼠标点击以约 0.55 秒的蓝色光圈扩散、淡出动画写入视频，连续点击可同时保留多个光圈。自身应用和其他应用中的点击均可记录，控制条按钮不写入点击效果；暂停时清除待显示光圈。只保留有限动画事件，不修改缓存的原始视频帧。

录制中 ⌥⇧R 暂停/继续，⌥R 结束并预览。Esc 仅取消选区或倒计时。菜单栏显示时间，控制条可拖动、隐藏和恢复，控制条和录制边界不写入视频。窗口最小化时暂停，窗口关闭或显示器断开时结束录制。锁屏、休眠、正常退出时封存已有片段，保留待保存状态，不自动导出或加入历史。

录屏是 MP4/H.264，声音为一条 AAC 混合音轨。逐帧写入磁盘，静止画面也维持录制时长；暂停同时移除视频与两种声音的时间。内存只保留有限画面和最多每路两秒待混声音，不把整个视频加载进内存。

录制只写入应用自有的临时片段目录。结束后先播放“待保存”预览；点击“保存…”并在系统保存窗口确认，才导出 MP4 并加入剪贴板历史。默认保存位置为“下载 / ClipHoook”，可在设置更改。取消保存可继续预览，关闭预览不会保存或删除，可从菜单栏“查看待保存录屏…”重新打开，正常退出后也可恢复。明确点击“放弃”才删除内部片段；保存失败时保留它供重试。完成确认前不提供向其他应用投放的文件操作，防止绕过保存确认。保存后可播放、复制、拖放、收藏、另存为及访达定位；历史只引用导出文件，删除历史不删除原视频。

待保存预览只保留视频画面里的原生播放／暂停按钮，与进度条、音量一起操作，不再在“裁剪时长”旁重复放置播放按钮。待保存预览提供“裁剪时长”，使用 macOS 原生播放器的首尾拖动交互，可预览所选片段、恢复完整时长，并选择省空间或原始清晰度。确认裁剪只记录起止时间，不改写原片段，也不生成历史记录；关闭、重新打开或正常重启后保留范围和画质。点击保存并确认位置后，才按所选范围同步导出视频与声音；先完成目标目录中的临时文件，再原子提交，失败或取消保留原片段及已有目标文件。

权限拒绝、没有收到画面、受保护窗口或编码/磁盘错误会显示原因。正常结束先封存到内部目录；确认保存时使用目标目录中的完整临时文件再原子提交，未收到画面不生成空视频；无法完成的临时片段留在内部目录，不承诺系统强制退出后一定恢复。

当前裁剪针对录制完成后的起止时间。macOS 14 起可用，macOS 26 使用原生玻璃控制条，旧系统使用系统磨砂材料。截图、标注和录屏的编辑状态分别保留。

## 验证边界

合成画面/音频的离屏检查覆盖共同暂停时间轴、两路声音混合、静止帧计时、H.264/AAC 可读取文件、无画面时清理，以及历史元数据重启恢复和引用文件保留。实际屏幕录制、声音设备、权限授予、系统菜单、选区/多屏/全屏和玻璃材质由用户桌面测试。本构建没有提交 App Store 审核。

## 冻结截图回归

截图进入冻结取景前，同时获取屏幕和可选窗口的快照；点击窗口从该批独立快照读取，不重新抓取后续视频画面。保持关闭冻结时的实时截图路径，保留原有窗口隔离与阴影选择。区域拖选继续裁剪冻结屏幕。冻结窗口缺失时报告不可截取，不静默回退为实时帧。视频帧一致性、多窗口遮挡与外接屏仍需桌面确认。
