# ClipHoook 隐私政策

生效日期：2026 年 10 月 17 日

运营者：任政霖  
联系邮箱：584772541@qq.com

## 1. 适用范围

本政策说明 macOS 应用“ClipHoook”（下称“本应用”）如何处理剪贴板内容及相关信息。请在启用剪贴板历史记录前阅读。本应用无需注册账号。

## 2. 本应用处理哪些信息

当“记录新复制的内容”处于开启状态且本应用正在运行时，本应用会检测 macOS 通用剪贴板的变化，并读取其中受支持的第一项内容：纯文本、以 http 或 https 开头的网页链接，以及 PNG、TIFF 图片。复制的内容可能包含姓名、联系方式、密码或其他敏感信息，具体取决于你放入剪贴板的内容。本应用不会主动读取其他应用中未复制的内容。

为了展示和管理历史记录，本应用还会在本机保存复制时间、来源应用的显示名称、内容大小、用于识别重复内容的摘要，以及外观模式、面板显示屏幕、弹出位置、尺寸、历史保存时间、最大存储量、是否暂停记录等设置。摘要用于本机去重，不用于识别你的身份。

本应用未集成广告或第三方分析 SDK，不要求账号，也不会把剪贴板历史上传至开发者服务器。若你主动发送支持邮件，我们会收到你在邮件中提供的地址和内容，并仅用于回复及处理该请求；请勿在支持邮件中发送不必要的敏感剪贴板内容。

## 3. 处理目的和方式

上述信息仅用于在本机记录、搜索、预览、排序和再次复制剪贴板历史，以及保存你选择的应用设置。你选择“复制”或双击记录时，本应用会将该记录写回 macOS 系统剪贴板。双击时，在你授予发送键盘事件权限后，本应用还会收起面板、切回先前的应用，并向该应用发送一次 ⌘V 粘贴快捷键。若未授权或目标应用不接受自动粘贴，你仍可手动按 ⌘V。系统剪贴板及目标应用对该内容的处理不由本应用控制。

## 4. 保存位置、期限与删除

历史索引和图片文件保存在当前 Mac 上的应用数据目录中。历史记录默认保存 7 天，你可以在设置中改为 1 天、15 天、30 天、半年或永久保存。到期记录会自动删除。默认不限制历史记录数量和总存储量；你也可以设置最大存储量，超过上限时本应用会从最早的记录开始删除，连同对应的图片文件。永久保存且不设置最大存储量时，本机空间占用可能持续增加。单条文字或图片超过应用限制时不会保存。

你可在本应用的“设置”中暂停后续记录，或选择“清空历史记录”删除本应用保存的历史索引和图片。暂停记录不会删除已有历史。清空历史不会清除 macOS 当前系统剪贴板，也无法删除你已粘贴到其他应用的副本。系统备份中的副本由你的 macOS 备份设置管理；卸载应用前如希望移除本机历史，请先在应用内清空。

## 5. 对外提供与第三方服务

本应用不会向开发者服务器、广告商或数据分析服务传输剪贴板历史，也不会出售这些内容。本应用使用 macOS 提供的剪贴板、窗口和快捷键能力；你在 App Store 下载应用及使用 macOS 系统服务时，Apple 对相关数据的处理适用其自身政策。你主动将内容复制到系统剪贴板或粘贴到其他应用后，该内容可能被相应应用按其规则处理。

## 6. 你的选择与权利

你可以在应用中查看历史详情、暂停记录、清空历史。你也可以通过 macOS“系统设置”管理本应用的剪贴板访问及发送键盘事件权限；撤销剪贴板访问权限后，自动记录可能无法继续工作，撤销键盘事件权限后，双击自动粘贴将无法使用。由于历史仅保存在你的设备上，开发者无法远程查看、修改或删除它。如需了解本政策、反馈问题或请求协助，请发送邮件至 584772541@qq.com。

## 7. 信息安全

Mac App Store 版本使用 macOS App Sandbox，历史文件保存在应用数据目录。本应用目前没有对本机历史文件再做一层独立加密；请妥善保护你的 Mac、系统账号与备份。若需避免保存某段敏感内容，可先暂停记录；若已保存，可及时清空历史。

## 8. 政策更新

若本应用的数据处理方式发生变化，我们会更新本政策的生效日期与内容，并在适当位置提供更新后的版本。如功能更新引入云同步、账号、分析服务或其他新的数据处理方式，我们会在启用前更新相应说明和必要的选择方式。
