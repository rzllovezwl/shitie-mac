# ClipHoook 开发预览版 349

适用于 macOS 14 及以上，Apple 芯片与 Intel 通用。应用版本为 1.0.0（349）；这是当前开发功能的预览版，与 App Store 正式版 1.1.0 分别维护。

## 下载与安装

下载 **ClipHoook-dev-349-universal.zip**，双击解压，将 **ClipHoook测试版.app** 拖入“应用程序”后打开。仓库自动生成的 Source code 附件为源码，请选择上面的应用压缩包。

应用使用 Developer ID Application 签名，已通过 Apple 公证并附加公证票据。分发包已完成解压、签名、公证票据及 Gatekeeper 校验。SHA256SUMS.txt 提供压缩包的 SHA-256 校验值。

## 可以体验的功能

- **iPhone 截图自动传到 Mac**：通过快捷指令和照片自动化，在同一可信局域网中把新截图传入 ClipHoook 历史。Mac 接收后可预览、识别文字、翻译、标注和拖放。[图文设置指南](https://github.com/rzllovezwl/shitie-mac/blob/develop/docs/iPhoneScreenshots.md)
- **剪贴板历史与全局搜索**：保存文字、链接、图片、富文本和文件引用；支持分类、收藏、多选、成组、排序、日期筛选、预览与 ⌘⇧空格快速搜索。
- **屏幕侧边暂存箱**：拖入内容暂存，单列缩略图滚动查看，再拖到目标应用；成功投放后移除，取消或未接收时保留。
- **截图与标注**：区域、窗口、整屏和长截图；裁剪、OCR、翻译、矩形、椭圆、箭头、组合箭头、划除等工具；标注元素可复制粘贴、按住 Option 拖动复制，并分别设置默认颜色和线宽。
- **录屏**：录区域、窗口或整屏，突出鼠标点击；停止后先预览、裁剪时长，再确认保存，默认使用省空间导出。
- **桌面贴图**：图片钉在桌面，缩放与透明度滑杆，工具条显示在图片上方。
- **复制反馈**：两张卡片交错再分开的 0.35 秒动效，十种本地提示音；默认短促双“咔嗒”，支持切换后自动试听和单独试听。

## 首次使用

从菜单栏打开面板，默认快捷键为 ⌘⇧V。区域截图为 ⌥A，录屏为 ⌥R。快捷键可在设置中修改。

截图和录屏需要系统屏幕录制授权；录制麦克风时需要麦克风授权；开发版直接粘贴需要系统键盘事件授权。拒绝直接粘贴授权后仍可复制，再在目标应用中手动 ⌘V。

iPhone 传图需 Mac 保持运行并开启接收，手机与 Mac 可在局域网互相访问。当前使用带随机配对码的本地 HTTP 地址，没有离线补传。请在可信网络中使用并保留自己的接收地址。
