# ClipHoook 2.0.0（12）桌面验证

使用构建 12 的商店候选进行验证。可在上传构建并处理完成后，通过内部 TestFlight 在真实 Mac 上安装。测试内容使用自建文字和文件。

## 准则 2.4.5 复测

1. 在系统设置中让 ClipHoook 的辅助功能权限保持关闭。打开 ClipHoook 设置，确认权限区显示屏幕录制相关入口。
2. 在文本编辑里复制一行临时文字。将插入点放到一个空白位置，按 ⌘⇧V 打开面板，双击刚才的卡片。面板收起，文本编辑保持原内容。亲自按 ⌘V 后才插入。
3. 分别从历史面板回车、⌥回车、右键复制和全局快速搜索回车测试。验证图片与文件复制、组合卡片、多选复制和纯文本格式。
4. 从已安装的 1.1.0（6）更新的情况下，核对原历史、设置、收藏和文件引用。有旧辅助功能授权的设备上也可复测双击与回车。

## 本次新增与重点功能

1. 按 ⌘⇧空格唤起快速搜索。用空查询、关键词和图片文字搜索测试。回车复制，⌘回车预览。
2. 拖动自建文件、图片和文字到暂存箱，再拖往可接收的测试应用。测试 Esc 取消、空格预览、侧滑收起和重新打开。
3. 按 ⌥A 冻结并选取一扇窗口或区域，松手后检查图像与保存结果。选中历史图片按 ⌘E，测试裁剪、标注复制和撤销。测试桌面贴图的缩放、透明度和工具条位置。
4. 按 ⌥R 选取区域并开始录制。测试暂停继续、鼠标点击提示和试听。结束后先验证待保存预览，裁剪一段再确认保存，检查 MP4 可播放且此时才出现历史卡片。另录一段并选择放弃，确认记录与文件状态符合预期。
5. 如需覆盖麦克风，在录屏选项主动打开后开始录制。验证权限提示内容和录制声音。需要时再验证同一局域网内的 iPhone 截图接收。

## 供审核附加的录屏

用文本编辑和临时文字录一段约 15 秒的演示。依次展示辅助功能关闭、双击卡片回到文本编辑、按下 ⌘V 后插入内容。录屏内可显示设定的版本与构建号，避免出现私人历史内容。
