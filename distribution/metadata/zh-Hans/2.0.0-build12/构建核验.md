# ClipHoook 2.0.0（12）构建核验

2026 年 11 月 19 日。本报告针对最终签名的 `ClipHoook-2.0.0-build12-AppStore.pkg`。

| 项目 | 结果 |
| --- | --- |
| 包内身份 | `com.renzhenglin.shitie`，2.0.0（12） |
| 源码 | 独立商店快照，以开发版 338 为基线 |
| 架构与系统版本 | arm64 与 x86_64，最低 macOS 14.0 |
| 签名 | Apple Distribution 应用签名与 Mac App Store 安装器证书链均通过本机验证 |
| 基础权限 | App Sandbox、用户选定文件读写、文件书签、下载目录读写、局域网接收、录屏麦克风 |

完整回归覆盖主面板与快速搜索的复制流程、纯文本与文件恢复、贴图焦点交接、剪贴板历史、收藏、暂存、桌面贴图、截图与标注，以及录屏草稿、暂停、时长裁剪、保存和点击动画。其中跨应用返回与窗口关闭使用隔离测试端点，录屏编码使用合成输入。

实际桌面上的快捷键、文本编辑手动粘贴、屏幕与麦克风授权、拖放和录屏设备仍待使用商店候选复测。本机结果与商店后台审核状态分别记录。[人工验证清单](人工验证清单.md)
