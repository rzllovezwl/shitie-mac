# 2.2.0（11）人工验证清单

以下项目留给你验证，本次自动检查不将其标记为已完成。先确认只运行待测的 ClipHoook，避免开发版与商店版同时争抢全局快捷键。先用非敏感测试内容。

| 场景 | 操作与预期 |
| --- | --- |
| 安装升级 | 通过 TestFlight 安装构建 11，关于显示 2.2.0（11），原历史与收藏保留；没有录屏入口或小组件说明。 |
| 暂存文件 | 从访达拖一个小文件和一份大文件到侧边暂存箱。应显示单列缩略图，原文件仍在，暂存不为大文件另存完整副本。 |
| 暂存独立内容 | 拖入图片、文字或链接，重启应用后仍在；空格可预览，图片可识别/翻译/标注/保存。 |
| 取出与取消 | 从暂存箱拖到支持接收的应用，成功后该项移除；另拖一项按 Esc，缩略图消失且该项保留；拒收也保留。无需发送测试文件。 |
| 收起与展开 | 非空时向屏幕侧边两指横滑，留下小标签，点它恢复；移除最后一项后隐藏。 |
| 全局搜索 | ⌘⇧空格打开；未输入显示最近最多 10 条。搜文字、文件名及图片内文字，↑↓选择、⌘↩预览、回车按设置粘贴。修改快捷键后新键生效。 |
| 搜索独立性 | 主面板先选分类/日期并横向浏览，再用快速搜索；关闭后主面板位置与条件保持。 |
| 卡片排序 | 单张和多选拖动换位；重启后顺序保留，历史与分类顺序分别记忆；分组可打开浏览。 |
| 编辑文字 | 文字卡片按 ⌘E 编辑，不保存时截图；取消截图后继续编辑，保存结果正确。图片 ⌘E 仍进入标注。 |
| 粘贴权限 | 在文本编辑、微信分别放好输入光标，双击卡片。未授权有手动粘贴提示；授权后如仍不生效，退出重开再试。桌面贴图在场时也验证一次。 |
| 截图与全屏 | 主屏、外接屏和全屏应用中拖选/点击窗口，标注工具可用；白底工具栏可辨识，完成只生成最终图片。受系统保护的窗口不应保存错误背后内容。 |
| 冻结点击复核 | 播放视频按截图键，停留数秒后点击选窗，与按键时的画面对照。这是用户刚报告的待修复路径，不能预先标记通过。 |
| 原有功能 | 日历、分类、面板钉住、桌面贴图、OCR、翻译、手动滚动长图和 ⌘S 导出作一次简短回归。 |
| 兼容性 | 有条件时在 macOS 14 真机验证启动和静态截图；14.4 系统翻译弹窗、15+ 本机翻译与语言资源分别测试。 |

验收结果和问题可直接按行记录；请勿将自动回归通过理解为上述桌面操作已验证。
