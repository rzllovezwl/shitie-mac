暂存箱,全局搜索,长截图,图片转文字,桌面贴图,分类收藏,文本编辑,OCR

## 描述

ClipHoook 是常驻菜单栏的剪贴板与截图工具。复制过的文字、链接、图片和文件，可以在本机历史中查找、整理并再次使用；还可以把内容放进侧边暂存箱，跨应用拖放。

默认按 ⌘⇧V 打开历史面板，按 ⌘⇧空格打开快速搜索。快捷键均可在设置中调整。

侧边暂存，跨应用接力
• 拖动文件、文件夹、图片、文字或链接时，在鼠标所在屏幕的一侧显示暂存箱。
• 内容以紧凑单列缩略图展示，支持滚动、多选和空格预览，也可从菜单栏手动打开。
• 放入后保持显示；成功拖到支持接收的应用后，对应项目从暂存箱移除，取消或未接收时保留。
• 向屏幕侧边两指横滑可收起为小标签，点击展开；空箱自动隐藏。
• 文件保存位置引用，独立图片和文字保存在本机；重启后继续使用，移除暂存不会删除原文件。

随时搜索，不打断当前任务
• 全局快速搜索采用独立浮窗，不改变主面板的分类、日期和浏览位置。
• 未输入时展示最近 10 条记录；输入后搜索文字、链接、文件名、来源及图片中的文字。
• 未识别的图片在本机逐张处理，已有结果先显示，后续匹配陆续补充并缓存。
• 用方向键选择、回车按设置粘贴，或 ⌘↩打开预览；Esc 返回或关闭。

按自己的习惯整理
• 创建与历史并列的收藏分类，设置名称和 Emoji 标识；分类可横向滚动，历史入口保持固定。
• 拖到分类即可收藏，拖到加号可新建分类并一起收藏。
• 常用卡片和分组可钉在面板前端，默认 ⌘⇧T；收藏和面板钉住内容跳过自动清理。
• 在面板内拖动卡片更换顺序，历史、收藏分类和分组分别保存顺序。
• 按内容类型、来源或日历日期查找，查看每天仍保留的记录数量。

编辑、复制与粘贴
• 文字和链接卡片按 ⌘E 直接编辑；富文本编辑后按纯文本保存。
• 多选复制、复制纯文本、分组及拖放；多选复制不会自动成组。
• 双击卡片可尝试返回原应用并自动粘贴，需要系统键盘事件权限及目标应用支持；也可仅复制后手动 ⌘V。
• 文本工具支持去空格、去多余空行、大小写转换、JSON 格式化及 Base64、URL、HTML 实体编码转换。
• 链接清理可先预览、勾选待删参数，保留有用参数和片段。

截图与可编辑标注
• 拖选区域或点击窗口，另有整个屏幕截图与手动滚动长截图。
• 支持冻结取景、八个锚点调整、局部放大和取色；窗口阴影可在设置中选择是否保留。
• 矩形、椭圆、箭头、文字、马赛克、背景模糊、荧光笔、画笔、序号和放大镜等工具，高级工具提供钢笔、贴图和区域高亮。
• 支持颜色与样式选择、移动和缩放标注、重新编辑文字；保留编辑数据的记录可再次打开修改。
• 图片卡片、预览、截图和标注均可保存为文件，默认 ⌘S，记住上次选择的文件夹。
• 工具栏适配明暗背景，提高白色画面上的边界辨识。

识别、翻译与桌面贴图
• 在图片、暂存预览及截图中识别文字，复制结果或翻译。
• 支持的系统上默认中译英、英译中，可选择其他语言；截图译文可直接覆盖在图片上。
• 图片可钉在桌面，拖动摆放、捏合缩放，调整至最低 10% 不透明度；右键复制，双击取消钉住。
• 可选接收 iPhone 快捷指令经可互访局域网发送的截图。

由你控制
• 历史保留时间、容量、排除记录的应用和快捷键均可设置。
• 文件默认引用原位置；访问受限时可选择文件或文件夹授权，完整副本由你主动选择保存。
• 无需注册，无广告或第三方分析 SDK，不向开发者上传历史内容。

支持 macOS 14 及更新系统。截图需要屏幕捕捉权限。macOS 15 及更新系统使用本机翻译接口，首次可能需要下载 Apple 语言资源；macOS 14.4–14.x 使用系统翻译弹窗，截图内覆盖翻译需要 macOS 15；macOS 14.0–14.3 不提供系统翻译。

长截图需手动滚动并保留重叠画面。系统或目标应用限制可能导致部分窗口无法截取。可编辑标注保留原始底图，分享遮盖内容请使用合并后的导出图片。

## 此版本的新功能

新增侧边暂存箱
• 拖入文件、图片、文字和链接，切换应用后继续拖出；文件引用原位置，不自动复制大文件。
• 单列缩略图、多选、空格预览，支持识别、翻译、标注和保存等适用操作。
• 成功投放后移除，取消或拒收时保留；侧滑收至屏幕边缘，点击恢复，重启后仍可使用。

新增全局快速搜索
• 默认 ⌘⇧空格，可自定义；未输入时展示最近 10 条，输入后搜索所有仍保留的历史。
• 支持文字、文件名、来源和图片内文字；键盘选择、预览及按设置粘贴。
• 独立搜索浮窗，不改变主面板的分类、日期和浏览位置。

整理与交互优化
• 面板内拖动更换卡片顺序，多选可一起换位，分类与分组分别保存顺序。
• 文字卡片按 ⌘E 直接编辑，改善编辑期间的截图入口。
• 优化拖动缩略图与鼠标的距离、Esc 取消和投放后的状态处理。
• 改善截图时 Dock 层级、Shift 多选后的浏览位置，以及标注工具栏在白色背景上的辨识。
• 更新应用内隐私说明和完整版本记录。

## App 审核备注（英文）

ClipHoook 2.2.0 (11) is a sandboxed menu-bar clipboard and still-image screenshot utility. No account or login is required. This submission is based on development build 322; it contains no screen recording feature and no widget extension.

Entry: use the menu-bar icon or Command-Shift-V. Copy some text and an image in another app to create history.

New in this update:
1. Staging shelf: drag a local file, image, text or link; a compact shelf appears at the side of the pointer's display. Drop content into it, then drag it to an app that accepts that type. Successful drops remove the shelf item; cancellation or rejection keeps it. Files reference their original locations. Independent image/text content is saved locally. Items survive restart. Swipe toward the display edge to collapse, and click the edge tab to expand. Space previews a selected item. Automatic appearance can be disabled in Settings > General, and the menu-bar menu can open the shelf manually.
2. Global quick search: Command-Shift-Space, configurable in Settings > Shortcuts. Empty query shows the latest 10 records. Type to find retained text, filenames, sources and locally recognized image text. Arrow keys select; Return performs the configured paste action; Command-Return previews; Esc returns or closes. Main-panel filters and position remain independent.
3. Drag cards within the panel to reorder. Command-E edits text cards or annotates image cards. Improvements cover drag image positioning, selection scrolling and annotation toolbar visibility on white backgrounds.

Existing capture: Option-A selects a region/window; Option-W captures a screen; Command-Shift-D starts manual scrolling capture. Finish/copy saves the final image. OCR is Command-W, translation Command-B, desktop image pin Command-T, and image export Command-S. Card pinning at the front of the panel is Command-Shift-T. All these shortcuts are configurable.

Permissions: screen capture access is used for still-image screenshots, frozen selection, magnification and manual scrolling capture, not video recording. File/folder access is user-selected. iPhone screenshot receiving is optional and off by default; it listens on the Mac for token-paired local-network uploads. There is no developer content server.

Automatic paste remains optional and user-initiated. It writes selected content to NSPasteboard, restores the target app, checks focus, then posts Command-V using Core Graphics after the required event-posting permission. AXUIElement APIs may compare focused element identity; they do not read the field's text. Manual Command-V is available if permission or focus validation fails. If newly enabled permission has not taken effect, quit and reopen the app as the in-app guidance explains. The app has no keystroke logging or arbitrary script execution.

macOS 14+ is supported. macOS 15+ uses Apple's on-device Translation framework; language downloads may be required. macOS 14.4–14.x uses the system text translation popover; image translation overlays require macOS 15+. Translation is unavailable on macOS 14.0–14.3.

History, staging items, OCR and annotation editing data are local. Editable annotations retain the original image; exported images flatten the effects. No advertising or third-party analytics SDK is included. Contact: 584772541@qq.com
