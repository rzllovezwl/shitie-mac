常见问题

如何打开剪贴板历史？

按 ⌘⇧V，或点击菜单栏中的 ClipHoook 图标并选择“打开剪贴板”。如快捷键无法使用，请检查是否与其他应用冲突。

如何粘贴一条历史记录？

双击记录后，ClipHoook 会将内容放回系统剪贴板、收起面板，切回刚才的应用，并向它发送 ⌘V。首次使用前，请在 ClipHoook“设置 → 快捷键与权限”中点击“打开键盘事件权限设置…”，在 macOS 系统设置中允许 ClipHoook 发送键盘事件；授权后如仍不能自动粘贴，请退出并重新打开 ClipHoook。若目标应用不支持粘贴，或当前没有可输入的光标位置，可手动在目标应用按 ⌘V。右键记录或在详情窗口中点击“复制”只会复制并收起面板。

如何查看图片和长文本？

单击记录选中，按空格打开详情；再次按空格收起详情。使用左右方向键切换记录。图片详情支持触控板双指捏合缩放。

历史记录保存在何处？如何删除？

历史记录保存在当前 Mac 的应用数据目录，不会上传到开发者服务器。在 ClipHoook“设置”中可暂停新记录，或点击“清空历史记录”删除本应用保存的历史。清空操作不会清除 macOS 当前系统剪贴板。

支持哪些内容？

当前版本支持纯文本、http 或 https 网页链接、PNG 和 TIFF 图片。不支持文件、富文本或其他剪贴板格式。历史上限为 100 条、总大小 100 MB。
